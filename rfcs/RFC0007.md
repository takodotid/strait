<h1 style="text-align: center;">[RFC#0007] Security</h1>

# Abstract

This RFC fixes what each Strait component may do in a cluster, which credentials exist and where they live, and how a link authenticates the site at the other end.

# Overview

| Asset | Threat | Control |
|---|---|---|
| The workload | Strait changes it by mistake or by compromise. | Read-only RBAC on workload resources. Plugins get a reader. |
| The link | A third party injects or reads traffic between sites. | WireGuard keys, or a private link declared trusted. |
| The WireGuard private key | It leaks. | Held in one Secret, read by the gateway agent only, never printed. |
| Other clusters | A compromised site reaches into another site's API. | No site holds credentials to another site. Sites share only the observation document. |
| Application data | Strait reads it. | Strait carries TCP and never parses it. Application TLS stays on. |

# Motivation

| Reason | Choice |
|---|---|
| A credential that is never issued cannot leak. | No kubeconfig of another cluster, no database credential. |
| Envoy parses data from peers, so it has the largest attack surface in the gateway. | Envoy gets no Kubernetes token, no capability, and runs as non-root. |
| A tunnel interface needs `NET_ADMIN`. | Only the gateway agent container gets it, and only in the gateway pod's network namespace. |
| A private link may already be trusted and encrypted below Strait. Encrypting twice costs CPU for nothing. | `encryption: None` is allowed on `direct` links, only when declared. |

# Requirements

## Permissions

1. The controller's RBAC MUST match the table in the Design section. Any rule beyond it is a change to this RFC.
2. The gateway agent's RBAC MUST match the table in the Design section. Its access to Secrets MUST be `get` on the one Secret named by `Site.spec.wireguard.privateKeySecretRef`.
3. The Envoy container MUST NOT mount a Kubernetes service account token. The gateway pod MUST set `automountServiceAccountToken: false` and mount a projected token into the agent container only.
4. Every Strait container MUST drop all capabilities and run with a read-only root file system. Only the gateway agent MAY add `NET_ADMIN`. Every container except the gateway agent MUST run as non-root. The gateway agent runs as root, since Kubernetes grants an added capability to a non-root process in its bounding set only. The gateway's namespace therefore needs the Pod Security level `privileged`.
5. The CLI MUST be read-only ([RFC#0006]).

## Credentials

6. The repository MUST NOT hold a secret value. Manifests MUST reference Secrets by name.
7. The WireGuard private key MUST come from a Secret in the gateway's namespace. The public key MUST be published in `Site.status.wireGuardPublicKey`.
8. No component MUST log or print a private key, a token or a Secret's data.
9. No component MUST hold credentials to another cluster's API or to a workload.

## Links

10. A `wireguard` link MUST accept traffic only from the peer key in `SitePeer.spec.wireguard.publicKey`, and only from the peer's tunnel address.
11. A `direct` link MUST declare `encryption: None`. The CRD MUST reject a `direct` link without it.
12. Over any link, a peer MUST reach only the gateway's control port and export ports. The import listeners and the peer listener MUST bind to the gateway pod's own address, so a tunnel address cannot reach them.
13. The control port MUST serve only `GET /healthz`, `GET /healthz/exports/<namespace>/<name>` and `GET /v1alpha1/observations`.
14. The gateway MUST forward an export's traffic only to that export's local Service ([RFC#0005]). It MUST NOT forward a peer's traffic onward to a third site.

# Design

## Controller RBAC

| API group | Resources | Verbs | Why |
|---|---|---|---|
| `strait.tako.id` | `siteservices`, `sites`, `sitepeers`, `sitelinks` | get, list, watch | Inputs. |
| `strait.tako.id` | `exports`, `imports` | get, list, watch, create, update, patch, delete | Owned by `SiteService`s. |
| `strait.tako.id` | `*/status` of the above | get, update, patch | Status. |
| core | `services` | get, list, watch, create, update, patch | Application names and gateway Services. |
| `discovery.k8s.io` | `endpointslices` | get, list, watch, create, update, patch, delete | Routes. |
| core | `pods` | get, list, watch | The active gateway's address. |
| `coordination.k8s.io` | `leases` | get, list, watch; create, update in its namespace | The gateway lease; its own leader election. |
| `events.k8s.io` | `events` | create, patch | Route changes and alerts. |
| `postgresql.cnpg.io` | `clusters`, `poolers` | get, list, watch | The `cnpg` plugin. |

## Gateway agent RBAC

| API group | Resources | Verbs | Why |
|---|---|---|---|
| `strait.tako.id` | `sites`, `sitepeers`, `sitelinks` | get, list, watch | WireGuard settings. |
| `strait.tako.id` | `sites/status`, `sitelinks/status` | get, update, patch | Public key, link health. |
| core | `secrets`, one name | get | The private key. |
| `coordination.k8s.io` | `leases`, in its namespace | get, create, update | The gateway lease. |

## Containers

| Container | User | Capabilities | Token |
|---|---|---|---|
| controller | non-root | none | yes |
| gateway agent | root in its own network namespace | `NET_ADMIN` | yes, projected |
| Envoy | non-root | none | no |

# Limitations

| Limitation | Trigger to revisit |
|---|---|
| The xDS stream between the controller and Envoy is not encrypted. It stays inside the Strait namespace, and a NetworkPolicy admits only gateway pods. | A cluster without NetworkPolicy enforcement. |
| The observation document is not signed ([RFC#0004]). | A transport without its own authentication. |
| Rotating the WireGuard key needs the peers' `SitePeer` updated at the same time. | Sites that must rotate keys often. |
