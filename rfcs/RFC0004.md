<h1 style="text-align: center;">[RFC#0004] Observation Exchange</h1>

# Abstract

Each site publishes what it observes about its own members as a read-only document on its gateway. Each peer polls that document over a link. This is how a site learns the state of remote members, and how it detects two writable members or sites that declare different primaries.

# Overview

| Step | Where |
|---|---|
| The controller observes local members through plugins. | Local site |
| The controller serves the observation document. | Local site, behind the gateway's control port |
| Each peer's controller polls the document through its own gateway, over the lowest-cost healthy link. | Peer |
| The peer's controller uses the document as input to its decisions ([RFC#0002]). | Peer |

# Motivation

| Reason | Choice |
|---|---|
| A site cannot see a remote member's state through the Kubernetes API of another cluster without credentials to that cluster. Credentials to another cluster's API widen the blast radius of a leak. | Each site observes only its own members, and shares only the result. No site holds credentials to another site's API. |
| Push needs a writable endpoint on every site. Poll needs only a read-only one. | Peers poll. The document is served for `GET` only. |
| Two clocks never agree exactly. | Freshness is measured on the reader's clock, from the time of the last successful poll. |
| A peer that cannot be read may still hold a writable primary. Treating it as having none would allow a second primary. | An unreachable peer is `Unknown`, never "no primary" and never `Multiple`. |

# Requirements

1. The controller MUST serve the document at `GET /v1alpha1/observations` and MUST refuse every other method with status 405.
2. The gateway MUST expose that path, and `GET /healthz`, on its control port to peers. It MUST NOT expose any other controller path.
3. The document MUST carry the site name, the generation time, and for every `SiteService` with a local member: each local member's observation and the site's declaration. It MUST also list the site's `Export`s with their gateway ports and readiness.
4. A site MUST report only its own members. A reader MUST ignore an observation whose member does not belong to the publishing site.
5. A reader MUST reject a document whose `site` is not the name of the `SitePeer` it polled, and MUST treat that peer as unreachable at once, without waiting for `peerTimeout`. It MUST also reject a document that lists a service, a member or an export twice.
6. A peer's controller MUST poll every peer every `Site.spec.exchange.pollInterval`. The default is 2s. Each request MUST time out within that interval.
7. A peer's document MUST be stale when the last successful poll is older than `Site.spec.exchange.peerTimeout`, measured on the reader's monotonic clock. The default is 6s. `peerTimeout` MUST be at least twice `pollInterval`.
8. While a peer's document is stale, every member at that peer MUST be `Unknown`, and that peer's declarations MUST be unknown.
9. A reader MUST reject a document larger than 4 MiB.
10. The poll MUST go through the local gateway, so it follows the same link choice as traffic.
11. `SitePeer.status` MUST show whether the peer is reachable, the time of the last successful poll, and the last error.
12. A controller replica that is not elected MUST NOT serve the document or poll peers. A replica that is not elected holds no observations, and an empty document would read as a site with no members. The controller runs as one replica with the `Recreate` strategy, and only the elected replica reports ready, so the controller's Service never sends a request to a replica that is not elected.
13. While a link to a peer is up, a change in the peer's document MUST show in the local site's decisions within `peerTimeout`. Checked by the end-to-end switchover test.

# Design

## Document

```json
{
  "apiVersion": "strait.tako.id/v1alpha1",
  "kind": "Observations",
  "site": "a",
  "generatedAt": "2026-10-27T10:00:00Z",
  "services": [
    {
      "namespace": "app",
      "name": "pg",
      "declaredPrimary": "pg-a",
      "members": [
        {
          "name": "pg-a",
          "role": "primary",
          "eligible": true,
          "state": "Stable",
          "reason": "ClusterPrimary",
          "observedAt": "2026-10-27T10:00:00Z",
          "addresses": ["10.110.1.5"],
          "port": 5432
        }
      ]
    }
  ],
  "exports": [
    { "namespace": "app", "name": "pg-pg-a", "port": 30901, "ready": true }
  ]
}
```

| Field | Use at the reader |
|---|---|
| `services[].declaredPrimary` | Rows 1, 2 and 4 of the `Single` decision ([RFC#0002]). Empty when the site declares none. |
| `services[].members[]` | The remote member's observation. |
| `services[].members[].addresses`, `port` | Endpoint-direct only ([RFC#0005]). |
| `exports[]` | The remote port of each `Import` ([RFC#0005]). |

A service is matched across sites by namespace and name. A member is matched by name.

## Path through the gateway

```
controller (site b) -> gateway b, peer listener -> link -> gateway a, control port -> controller (site a)
```

The gateway's peer listener routes `/peers/<peer>/...` to that peer's control port over the link chosen as in [RFC#0005]. The controller never dials a link itself, so `wireguard` interfaces stay inside the gateway.

# Implementation

| Path | Holds |
|---|---|
| `internal/exchange/document.go` | The document types and their validation. |
| `internal/exchange/local.go` | The local site's observations and exports, as the reconcilers set them. |
| `internal/exchange/server.go` | The read-only HTTP handler. |
| `internal/exchange/poller.go` | The poller and freshness. |
| `internal/exchange/sitepeer.go` | `SitePeer` status. |

# Security Considerations

- The document holds member names, roles, states, and, for endpoint-direct, pod addresses. It holds no credentials.
- Over a `wireguard` link, only the holder of the peer's key can reach the control port. Over a `direct` link, the link is trusted by declaration ([RFC#0005], [RFC#0007]).
- A forged document could claim a second writable member, which routes nowhere, or hide one. Hiding one is the same risk as a partition, covered in [RFC#0002].

# Limitations

| Limitation | Trigger to revisit |
|---|---|
| No signature on the document. Integrity rests on the link. | A transport without its own authentication. |
| Full document on every poll. | Documents large enough that polling every 2s costs real bandwidth. |
